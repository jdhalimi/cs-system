# Données de travail

Ce répertoire est volontairement ignoré par Git : il peut contenir des données
personnelles et des documents de copropriété.

- `exports/` : snapshots bruts, datés et immuables, issus des services.
- `cache/` : réponses ou représentations techniques remplaçables.
- `indexes/` : index reconstruisibles, optimisés pour les recherches locales.
- `local/` : jeux de travail et résultats de pipelines locaux.

Les rapports humains sont écrits dans `../reports/` et les jetons / curseurs
techniques dans `../.state/`.
